# RSI Divergence Scanner

เว็บแอพไฟล์เดียวสำหรับสแกนเหรียญบน Binance Spot (คู่ USDT) ที่มี RSI divergence
รองรับหลาย timeframe พร้อมกัน (Week / Day / 4h / 1h / 15m) และแจ้งเตือนเมื่อพบสัญญาณใหม่

- ดึงราคาจาก Binance public API ตรงจากเบราว์เซอร์ ไม่ต้องใช้ API key ไม่มี backend
- ตรวจ divergence จากจุด pivot ของราคาเทียบกับ RSI ที่แท่งเดียวกัน
- นับ "ลูกที่กำลังเกิด" (ราคาทำจุดใหม่แล้วแต่ยังไม่ครบแท่งยืนยัน pivot) เพื่อให้สัญญาณมาเร็วขึ้น
- กราฟในแอพด้วย Lightweight Charts และลิงก์เปิด TradingView ต่อเหรียญ
- ติดตั้งเป็น PWA บนมือถือได้ (เพิ่มไปหน้าจอหลัก)

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages แล้วกด "เริ่มสแกน"
